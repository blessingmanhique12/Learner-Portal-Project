# Learner-Portal-Project

## PROBLEM STATEMENT:
SkillsTrack Training Centre supports learners who attend short occupational programmes. Learners currently
record goals, tasks, support bookings and progress in separate documents and messages. Assessors struggle
to see what work is outstanding, which learners need support, and whether learners are making progress.

Project Overview

The Learner Support Portal is a web-based application designed to provide learners with a central platform for accessing learning resources and services. This repository serves as the single source of truth for all project documentation, designs, planning artefacts, source code, and project deliverables.

**Client Brief Summary**

The project is based on the client brief provided by the facilitator.

The objective is to develop a Learner Support Portal that meets the client's functional and non-functional requirements while following software development best practices.

Git Branching Strategy

- "main" contains stable code.
- Each team member works on a separate feature branch.
- Changes are submitted using Pull Requests.
- Code is reviewed before merging into the main branch.

Contribution Guidelines

- Create a new feature branch before starting work.
- Write meaningful commit messages.
- Commit changes regularly.
- Open a Pull Request when your work is complete.

- Keep documentation up to date.
